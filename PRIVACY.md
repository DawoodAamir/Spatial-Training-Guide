# Privacy

The app stores a local progress record containing its format version, number of completed checkpoints, and update time in private Application Support storage. Restarting practice replaces that record after confirmation.

No analytics, accounts, advertising, network requests, or third-party services are included. The app requests no camera, microphone, environmental sensing, or physical object-tracking access. Part selections use system-targeted RealityKit interaction events.

The original practice model and lesson contain no personal data. Debug UI tests use an isolated library selected by a validated random identifier; that override is absent in Release builds.
