# Contributing

Use Xcode 27 and Swift 6. Keep scene entities and UI state on the main actor, checkpoint rules in TrainingCore, and file writes in TrainingStore. Advance only after durable persistence succeeds.

Run Debug/Release core tests, simulator/device builds, and the native workflow for interaction changes. Document physical-device checks separately. Do not describe in-app answers as validation of physical work. Any future reference-object tracking feature needs a legitimately trained asset and device verification.

Regenerate the original layered icon with `swift Scripts/GenerateIcon.swift "$PWD"`. Geometry is generated by AssemblyScene. Use concise Conventional Commits.
